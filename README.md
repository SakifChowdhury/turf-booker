## About the project

Turf Booker is a planned website for booking sports turfs in Dhaka. Today most
turfs are booked through phone calls and social-media messages, which leads to
missed messages, double bookings and no record of payments. Turf Booker aims
to put every turf's schedule online so players can see free hours and book in
a few clicks, while turf managers get one place to run their turfs.

## Planned features

**Players**
- Create an account and log in
- Browse turfs by area and sport
- See each turf's free hours and prices for the next two weeks
- Book a slot, follow its status and cancel if plans change
- Pay in cash at the turf
- Get notified when a booking is confirmed, rejected, cancelled or paid

**Turf managers**
- Add and manage turfs, prices and opening hours
- Approve or reject booking requests
- Record cash payments
- See a dashboard of today's games and upcoming bookings
- Keep a small customer list with notes

**Admin**
- Manage all users, turfs and bookings
- Send announcements
- Review a log of admin actions
